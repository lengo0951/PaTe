# Phase 02: TDD Win32 Clipboard Listener & Type Extraction

## 🎯 Objective
Xây dựng module lắng nghe sự kiện Clipboard toàn hệ điều hành bằng Win32 API (`AddClipboardFormatListener`), trích xuất nội dung văn bản (Unicode text), đường dẫn URL, mã màu HEX, và chống vòng lặp tự dán.

## 🧪 TDD Specification

### 1. Test Cases (`tests/clipboard_test.rs`)
* `test_classify_plain_text()`: Xác định chuỗi text thường là `ContentType::Text`.
* `test_classify_url()`: Chuỗi bắt đầu bằng `http://` hoặc `https://` được phân loại là `ContentType::Link`.
* `test_classify_hex_color()`: Chuỗi dạng `#FFFFFF`, `#0A84FF` được phân loại là `ContentType::Color`.
* `test_classify_code_snippet()`: Chuỗi chứa từ khoá lập trình (`fn `, `struct `, `const `, dấu ngoặc kép) là `ContentType::Code`.
* `test_self_paste_suppression()`: Khi clipboard chứa format định danh tùy biến `PasteFlowAutoGenerated`, module bỏ qua không lưu lại.

### 2. Implementation (`src/core/clipboard.rs`)
* Tạo message-only window ẩn bằng `CreateWindowExW(0, L"STATIC", ...)`.
* Gọi `AddClipboardFormatListener(hwnd)`.
* Trong vòng lặp thông điệp `GetMessageW`, bắt `WM_CLIPBOARDUPDATE`.
* Mở clipboard an toàn bằng `OpenClipboard` và đọc `CF_UNICODETEXT`.

## 🧪 Acceptance Criteria
- [ ] 100% Unit Tests trong `tests/clipboard_test.rs` đều PASS (Green).
- [ ] Bắt tức thì khi người dùng copy ở bất kỳ app nào trên Windows với độ trễ < 2ms.
- [ ] Không gây rò rỉ bộ nhớ (Zero leak với `GlobalLock` / `GlobalUnlock`).
