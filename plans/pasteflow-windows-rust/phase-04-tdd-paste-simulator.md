# Phase 04: TDD Win32 Paste Simulator & Plain Text Pasting

## 🎯 Objective
Sử dụng Win32 `SendInput` để gửi sự kiện dán `Ctrl + V` vào ứng dụng đang làm việc. Cung cấp tính năng **Paste as Plain Text** (xóa bỏ toàn bộ định dạng) và cơ chế ẩn cửa sổ HUD trước khi dán.

## 🧪 TDD Specification

### 1. Test Cases (`tests/paste_test.rs`)
* `test_send_input_keystroke_sequence()`: Kiểm tra chuỗi INPUT events được tạo đúng thứ tự: `VK_CONTROL` down -> `V` down -> `V` up -> `VK_CONTROL` up.
* `test_strip_formatting()`: Kiểm tra hàm `to_plain_text()` loại bỏ ký tự HTML tags, RTF format headers, chỉ giữ lại chuỗi Unicode thô.
* `test_active_window_focus_recovery()`: Kiểm tra `SetForegroundWindow` khôi phục lại cửa sổ của ứng dụng đích trước khi bắn `SendInput`.

### 2. Implementation (`src/core/simulator.rs`)
* `fn paste_item(item: &ClipboardItem, as_plain_text: bool) -> Result<(), Error>`
* Gắn format ẩn `PasteFlowAutoGenerated` lên clipboard trước khi bắn phím dán để module listener không tự động thu thập lại clip này.

## 🧪 Acceptance Criteria
- [ ] 100% Tests mô phỏng keystrokes pass.
- [ ] Dán mượt mà vào Notepad, VS Code, Chrome, Microsoft Word mà không làm mất focus.
