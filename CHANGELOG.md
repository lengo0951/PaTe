# Changelog - PasteFlow

All notable changes to **PasteFlow** will be documented in this file.
This project adheres to [Semantic Versioning](https://semver.org/).

---

## [1.1.0] - 2026-11-24

### 🚀 Features (Added)
* **Native Swift 6 + SwiftUI + AppKit Architecture**: Completely zero Electron / Webview dependencies, ensuring maximum performance and compatibility with macOS 13 (Ventura) through macOS 15+ (Sequoia).
* **Frosted Glassmorphism Floating Bar**:
  * Sleek HUD anchored to the bottom edge of the display with fluid `NSVisualEffectView` Material blur.
  * Seamless automatic adaptation to macOS Light and Dark modes.
* **Instant Quick Look (`Spacebar`)**:
  * Tap the Spacebar on any highlighted card to expand into a full-size modal preview.
  * Supports high-resolution images, syntax-aware code snippets, color palettes (HEX / RGB / SwiftUI Color), and file attachment summaries.
* **Smart Keyboard Shortcuts & Pure Pasting**:
  * `⌘ + ⇧ + V` (`Cmd + Shift + V`): Global toggle shortcut to reveal/dismiss PasteFlow from anywhere.
  * `Return`: Automatically simulates `Cmd + V` paste into the target application.
  * `⌥ + Return` (`Option + Return`): **Paste as Plain Text** — automatically strips styles, formatting, font colors, and rich markup.
  * `1` to `9`: Instant single-key paste for the 9 most recent clipboard items.
  * `Delete` / `Backspace`: Remove selected card from history.
* **Privacy-First & Loop Protection**:
  * Automatically detects and suppresses confidential data copied from password managers (**1Password**, **Bitwarden**, **KeePassXC**, **Keychain Access**).
  * Self-paste infinite loop prevention using `org.nspasteboard.AutoGeneratedType`.
* **Custom Pinboards**: Organize snippets, commands, links, and assets into dedicated color-coded tabs.
* **One-Click DMG Package**: Includes automated packaging script `package_dmg.sh` generating an optimized 1.6 MB compressed disk image with an `/Applications` drag-and-drop link.

### ⚡ Performance & Memory Optimizations
* **Eliminated TIFF Bitmap Bloat**:
  * Replaced uncompressed 1024×1024 raw icon extraction (~98MB/icon) with an intelligent `AppIconCache` that downscales icons to 32×32 and enforces an LRU capacity of 64 entries.
  * Reduced real resident memory (RSS) from 1.91 GB down to **~33 MB** (over 95% reduction).
  * Reduced history database file size from 2.6 GB down to ~370 KB.
