# PasteFlow v1.1.0 ⚡

**PasteFlow** is a next-generation, lightweight, and privacy-first clipboard manager built natively for **macOS** and **Windows**, crafted by [**Quốc Ngô**](https://github.com/lengo0951) (`@lengo0951`).

---

### 🌟 Release Highlights (v1.1.0)

#### 🍎 macOS Edition (Swift 6 & SwiftUI & AppKit)
* **🎨 Frosted Glassmorphism Floating Bar:** Sleek bottom HUD matching macOS Sequoia and Sonoma design language with native `NSVisualEffectView` materials and seamless Light/Dark mode switching.
* **⚡ Ultra-Low Memory Footprint (~31 MB RAM):** 100% Native Swift 6 + SwiftUI + AppKit — zero Electron or Webview dependencies. Idle CPU consumption sits at near 0.0%.
* **🔍 Instant Quick Look (`Spacebar`):** Press Spacebar on any clip to trigger a full-size modal preview for full-resolution images, multi-line code snippets with syntax highlighting, color swatches with HEX/RGB values, and file lists.
* **⌨️ Smart Keyboard Shortcuts & Pure Pasting:**
  * `⌘ + ⇧ + V` (`Cmd + Shift + V`): Toggle PasteFlow HUD from anywhere without requiring Accessibility permissions for activation.
  * `Return`: Direct paste simulation into the frontmost app.
  * `⌥ + Return` (`Option + Return`): Paste as Plain Text — automatically strips rich text, styles, and unwanted formatting.
  * `1` through `9`: Quick paste for the 9 most recent items.
  * `Delete` / `Backspace`: Remove selected item from history.
* **🛡️ Privacy-First & Loop Prevention:** Automatically ignores clips from password managers (1Password, Bitwarden, KeePassXC, Keychain Access) and prevents feedback loops with `org.nspasteboard.AutoGeneratedType`.
* **🏷️ Custom Clip Renaming & Tagging:** Set custom labels or names on any clipboard snippet (Press `R` or right-click to Rename). Filter and search clips instantly by custom title or snippet text.
* **🗂️ Custom Pinboards:** Organize snippets, commands, links, and assets into dedicated color-coded tabs.

#### 🪟 Windows Edition (Rust 2024 & Win32 APIs)
* **💎 Native DWM Acrylic / Mica Blur:** Built entirely with `windows-rs` 0.58. Leverages `DwmSetWindowAttribute` for true Windows 11 Acrylic frosted glass and rounded corners (`DWMWCP_ROUND`).
* **🚀 Extreme Performance (~20 MB RSS):** Zero-overhead Win32 message loop with `WM_CLIPBOARDUPDATE` format listener and GDI double-buffered rendering.
* **⌨️ Ergonomic Hotkeys:** `Ctrl + Shift + V` HUD toggle, Spacebar Quick Look modal, and `SendInput` keystroke synthesis for instantaneous clipboard delivery.
* **🔒 Privacy & Isolation:** Protected local storage in `%APPDATA%\PasteFlow` with JSON serialization and automatic sensitive clipboard filtering.

#### ⚡ Action & Navigation Latency Optimizations (v1.1.0-hotfix)
* **🏎️ Zero-Latency Navigation:** Short-circuited `filteredItems` to O(1) in the default state and accelerated scroll animation to 80ms, eliminating any visual delay when cycling through clips with arrow keys.
* **⚡ Instant Double-Click Paste:** Removed SwiftUI single-tap disambiguation penalty (~300ms) and eliminated artificial delay timers (250ms). Double-clicking any card now orders out the HUD immediately and synthesizes paste keystrokes in under 25ms.
* **🖱️ Full Windows Mouse Support:** Added `CS_DBLCLKS` window class style, `WM_LBUTTONDOWN` instant selection, and `WM_LBUTTONDBLCLK` immediate paste on Windows.

### 📦 Installation

#### macOS
1. Download `PasteFlow-1.1.0.dmg` below (2.1 MB).
2. Open the `.dmg` and drag `PasteFlow.app` into your Applications folder.
3. Launch PasteFlow and grant Accessibility permissions when prompted so it can automatically simulate `Cmd + V` paste events.
4. Press `⌘ + ⇧ + V` to summon PasteFlow!

#### Windows
1. Download `PasteFlow-v1.1.0-windows.zip` below.
2. Extract the archive and run `pasteflow.exe`.
3. Press `Ctrl + Shift + V` to summon PasteFlow!
